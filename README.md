Workforce Analytics Project

Overview
This project analyses employee work patterns across departments and projects to understand workload distribution, project allocation and operational efficiency.

-Tools Used
- VS Code
- Python (pandas)
- SQL
- matplotlib

Analysis Completed
- Joined datasets (employees, projects, work logs)
- Analysed hours worked by employee
- Compared workload by department
- Measured project-level effort
- Created calculated columns for effort classification
- Generated business insights from data trends

Key Insights
- Engineering had the highest workload concentration
- Some employees handled disproportionately more work than others
- Project efficiency varied significantly across projects
- Higher-budget projects did not always require more effort

Skills Demonstrated
- Data cleaning
- Data merging
- GroupBy aggregations
- Sorting & filtering
- Feature engineering
- SQL joins
- KPI thinking
- Business insight generation
